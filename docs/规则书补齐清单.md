## 数据来源与口径

- 规则书：集石规则书页逐页下载原图 → OCR → 语义切片 → 向量化；原始页存 `frontend/public/rules/<slug>/page-N.jpg`，前台可翻阅。
- 规则文档：切片文本 + 向量，只供 AI 检索，与管理端的「规则书（原始文件）」分开存储（`rule_books` / `rule_documents` 两张表）。
- 替换进来的 4 款，元数据取自集石游戏页（年份 / 分类 / 支持人数 / 设计师 / 出版社 / 中文简介）；
  集石没有的字段（BGG 编号、年龄、单局总时长、机制、获奖、视频、玩家图）一律留空，前端显示「暂无」，不做推测补全。
- 向量模型：`text-embedding-v4`（dimensions=1536），全库切片统一重算，不混用不同向量空间。
